# 模块快捷入口功能说明

## 概述

模块快捷入口是 sleveen-admin 首页的核心导航组件，位于页面顶部概览区域。该组件采用现代化卡片悬浮设计，提供九大业务板块的快速访问入口，支持三级菜单层级结构，让用户能够高效定位并进入目标功能模块。

## 功能特性

### 1. 九大业务板块

快捷入口涵盖平台所有核心业务模块：

| 模块名称 | 功能描述 | 菜单层级 |
|---------|---------|---------|
| 生产运营 | 产量、进尺、计划、对标 | 三级菜单 |
| 安全风险 | 风险辨识、隐患、管控 | 三级菜单 |
| 机电运输 | 设备状态、巡检运维 | 直接跳转 |
| 技术监管 | 技术资料、专项监督 | 直接跳转 |
| 一通三防 | 通风、瓦斯、矿灭火 | 直接跳转 |
| 应急指挥 | 应急调度、事件处置 | 直接跳转 |
| 综合管理 | 考核统计、作业合规 | 直接跳转 |
| 视频专题 | 视频专题实时监控 | 直接跳转 |
| 我的工作台 | 待办、消息、工作指引 | 直接跳转 |

### 2. 三级菜单结构

支持三级层级导航，以"生产运营"模块为例：

```
生产运营 (一级)
├── 产量 (二级)
│   ├── 煤炭产量日填报 (三级)
│   ├── 煤炭产量月计划 (三级)
│   └── 产量完成情况 (三级)
├── 进尺 (二级)
│   ├── 掘进进尺日填报 (三级)
│   └── 进尺月计划 (三级)
├── 煤质 (二级)
│   ├── 煤质日报 (三级)
│   └── 煤质月报 (三级)
└── 生产接替 (二级)
    └── 采掘接续计划 (三级)
```

### 3. 交互设计

#### 悬停展开
- 鼠标悬停在带下拉箭头的模块卡片上时，自动展开大卡片悬浮菜单
- 采用毛玻璃效果（backdrop-filter）和柔和阴影，视觉层次清晰
- 展开动画使用 cubic-bezier 缓动函数，流畅自然

#### 直接跳转
- 无子菜单的模块（如机电运输、技术监管等）点击后直接跳转至对应页面
- 有子菜单的模块需通过悬浮菜单选择具体功能项进入

#### 视觉反馈
- 悬停时卡片轻微上浮并显示阴影
- 左侧彩色边框区分不同模块（蓝、绿、橙、紫循环）
- 三级链接悬停时高亮显示，小圆点放大变色

## 技术实现

### 数据结构

```typescript
interface MenuItem {
  label: string;
  path?: string;
  children?: MenuItem[];
}

interface ModuleEntry {
  title: string;
  desc: string;
  path?: string;      // 直接跳转路径（无子菜单时）
  children?: MenuItem[]; // 子菜单（有下级时）
}
```

### 核心样式

- **卡片布局**：CSS Grid 三列布局，响应式适配
- **悬浮菜单**：绝对定位，宽度 360px，双列展示二级分类
- **层级管理**：z-index 层级控制确保菜单不被遮挡
- **溢出处理**：overview-card 和 overview-main 设置 `overflow: visible` 允许菜单溢出

### 事件处理

- `@click`：无子菜单时直接跳转
- `@click.stop`：子菜单项点击时阻止冒泡
- 悬浮状态通过 CSS `:hover` 控制，无需 JavaScript 状态管理

## 使用指南

### 快速访问功能

1. **直接访问**：点击无箭头的模块卡片（如"机电运输"），直接进入该模块首页
2. **分级导航**：悬停带箭头的模块卡片（如"生产运营"），在展开的菜单中选择具体功能
3. **精准定位**：通过二级分类快速找到目标功能，如"产量"→"煤炭产量日填报"

### 扩展配置

如需添加新的模块或功能：

1. 在 `quickModuleEntries` 数组中添加新的模块对象
2. 设置 `title`（模块名称）、`desc`（简短描述）
3. 如需三级菜单，配置 `children` 数组；如需直接跳转，设置 `path`
4. 确保路由路径正确配置

## 设计亮点

1. **空间利用率高**：一级入口简洁，悬浮时才展示详细菜单
2. **视觉层次分明**：毛玻璃效果、阴影、圆角营造现代感
3. **交互流畅**：平滑的动画过渡，无闪烁或卡顿
4. **可扩展性强**：数据驱动结构，易于添加新模块
5. **响应式友好**：适配不同屏幕尺寸，移动端自动调整布局

## 注意事项

- 悬浮菜单依赖 `overflow: visible` 设置，修改相关样式时需注意
- 三级菜单路径需与项目路由配置保持一致
- 建议模块数量保持在 9 个以内，确保布局美观
