# sleveen-admin / sailflow 宿主适配层对齐核对

> 状态：现行（2026-11-14）  
> 基准：pxxt8 `api8/sailflow`（`AddSailflowHost` + `doc/宿主插件注册清单.md`）  
> 对照：本仓 `backend/sailflow`  
> 本轮范围：核对 + **P0 伪实现** + Foundation TP 风格控制台；**不做 P1**。

组合根：`SleveenAdmin.Sailflow.Hosting.SailflowHostSetup.AddSailflowHost`。

| 能力 | 双方状态 |

| `UseFlowEventFileLog` / `UseInstanceLockCleaner` | 启用 |
| Controllers：Wf2Xml(+Runtime)、WfBizForm、WfLeave、WfForm、Wf2Ai、WfCategory、WfProcessEdit、WfCopyto、WfVariable、WfOutbox、WfReport、RuleSet、FineUpload、Workbench、Probe | 均有 |

## 2. P0 伪实现（本轮已挂）

| 项 | 入口 | 行为 | 明确不做 |
|----|------|------|----------|
| **TP 风格控制台基建** | `SleveenAdmin.Foundation.Diagnostics.DevConsole` + `SailDevConsole` | 分节标题 + `##标签## 值` | 不依赖 Furion |
| **Debug 控制台** | `UseDebugConsoleHook` | Sync Hook + AsyncOutbox Notifier → 控制台；内挂 Outbox Drain | — |
| **BizMirror** | `UseBizMirrorHook`（`BizMirror/SailBizMirrorStubHook`） | Continued/终态 → `WriteHook("业务回写")` | 不建 `sf_biz_flow`、不投影 |
| **门户补推** | `api/WfPortal/SyncPush` + `SailPortalSyncService` | 控制台占位后返回 stub 结果 | 不接 UnifiedReport HTTP、不真实回填 |

伪实现类均标注：`// stub: console-only; real port later`。
