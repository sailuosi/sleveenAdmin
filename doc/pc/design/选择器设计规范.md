# PC 端业务选择器设计规范

> **基座**：`web/src/ui/input/sh/selectorbase.vue`  
> **相关**：[代码风格规范.md](./代码风格规范.md) §8 UI 分层；[biz-module-paradigm.md](./biz-module-paradigm.md)

本文约定表单内「可搜索下拉 + 弹窗富选」选择器的设计、目录结构与使用方式。新建选择器按本规范落在对应业务 widget 的 `uiext` 下。

---

## 1. 目标与边界

### 1.1 目标

- **表单友好**：作为 `el-form-item` 控件使用，支持 `label` / `prop` / `v-model:fk` / `v-model:name`。
- **双通道选取**：关键字快速下拉 + 「更多」打开业务弹窗（Biz 页 / 专用面板）精细选取。
- **职责分离**：基座负责交互壳；业务 put 负责字段映射；轻量 API 负责下拉；Biz Select 页负责富列表。

### 1.2 适用场景

| 适用 | 不适用 |
|------|--------|
| 表单中绑定外键 + 显示名 | 纯列表页勾选（用 VC/`checkable`） |
| 需要下拉快搜 + 弹窗深选 | 仅一次性弹窗且不落表单控件（可直接挂 Biz 页） |
| 单选为主，可扩展多选 | 复杂向导式多步（用独立流程页） |

### 1.3 不在本文范围

- 字典下拉（`fminput` + dict）、纯树选择等非「搜索 put」控件。
- 平台生成 VC/Page 内部列表能力本身（选择器只消费它们）。

---

## 2. 分层架构

```
业务页 / 表单
  → xxxput.vue（字段映射、onload、挂富选页）
       ├─ selectorbase（交互壳：表单项 / 下拉 / 更多弹层）
       ├─ uipart/*row（下拉行展示）
       ├─ 轻量 Selector API（top N 快搜）
       └─ Biz_*Select / 面板（富选分页列表）
```

| 层 | 职责 | 典型路径 |
|----|------|----------|
| 基座 | 表单项、搜索框、下拉列表、更多弹层插槽 | `web/src/ui/input/sh/selectorbase.vue` |
| 业务 put | 字段映射、onload、挂富选 | `web/src/widgets/{widget}/uiext/selector/<域>/<name>put.vue` |
| 行展示 | 下拉 option 可读摘要 | `.../selector/<域>/uipart/<name>row.vue` |
| 下拉 API | 轻量、无分页或 top N、按关键字 | widget 内 `api/` + 后端 Selector / Biz 轻量接口 |
| 富选页 | 完整列表、筛选、勾选确认 | `widgets/{widget}/.../Page/**/Biz_*Select*.vue` |

---

## 3. 目录与命名

### 3.1 业务选择器（推荐）

```
web/src/widgets/{widget}/uiext/selector/
  <域>/
    <实体>put.vue
    uipart/
      <实体>row.vue
```

组织/人员类可放在 `uiext/org/`（如 `humaninput.vue`），结构仍遵循「selectorbase + onload + mbody」；新建同类优先 `selector/<域>/`。

示例落点：`widgets/officeman/uiext/selector/`、`widgets/sysext/uiext/selector/`。

### 3.2 命名约定

| 类型 | 约定 | 示例 |
|------|------|------|
| 选择器组件 | `<语义>put.vue` | `ebcataput.vue` |
| 下拉行 | `<语义>row.vue` | `ebcatarow.vue` |
| 前端下拉 API | `loadXxxSelector` | `loadEbCataSelector` |
| 后端路由 | `POST /biz/{slug}/sh/<短名>` 或域内自定轻量前缀 | 与 PageApi 同风格 |
| 富选页面 | `Biz_<业务>Select` | `Biz_Sa_EbCataSelect` |

## 4. 业务 put 组件结构

### 4.1 模板骨架

```vue
<selectorbase
  ref="selectorbaseRef"
  :label="label" :prop="prop" :span="span" :labelWidth="labelWidth"
  :onload="loadList" :rowKey="pk"
  :mtype="type" :mwidth="width" :mheight="height" :mplacement="placement"
  :useMorePanel="true"
  :useAuth="useAuth" :bpo="bpo"
  @select="onSelect($event)"
  v-model:fk="fk"
  v-model:name="name"
>
  <template #tag>
    <slot>{{ loadName() }}</slot>
  </template>
  <template #option="opt">
    <xxxrow :row="opt.row" />
  </template>
  <template #mbody="mbp">
    <Biz_XxxSelect
      :param="param"
      @select="onRichSelect($event, mbp)"
      @close="mbp.close"
    />
  </template>
</selectorbase>
```

- `#option`：下拉每一行；复杂展示抽到 `uipart/*row`。
- `#mbody`：更多弹层；确认后 `mbp.close()`。
- 有富选时 **`useMorePanel` 固定为 `true`**。

### 4.2 数据绑定

| 绑定 | 含义 | 规则 |
|------|------|------|
| `v-model:fk` | 外键 / 主键 OID | 必选 |
| `v-model:name` | 展示名 | 必选 |
| 扩展 model | 关联字段回填 | 按需 |

**禁止**把复杂对象塞进单个 `v-model` 当外键；需要整行用 `@select`。

### 4.3 选择与确认

1. 下拉点选 → 写 `fk`/`name` → `emit('select', row)`  
2. 弹窗确认 → 适配富选事件（`@select` / `@confirmRows` / `@confirm`）→ 取约定行 → 写 fk/name → `emit('select')` → `mbp.close()`  
3. 对外统一 `emit('select', row)`，不把富选原始事件名泄漏给业务页  

```js
defineExpose({
  openMorePanel: () => selectorbaseRef.value?.openMorePanel?.(),
})
```

### 4.4 下拉加载

```js
function loadList(para) {
  return loadXxxSelector(para).then(res => res.data); // 必须返回数组
}
```

`rowKey` 使用实体主键字段名（如 `Sa_EbCataOID`）。

## 5. 下拉行与 API

- `*row`：**只展示**，不发请求、不写回表单；空标题显示 `—`。
- 下拉 API ≠ 列表 `qlist`：前者轻量 `top(50)` 快搜；后者完整分页/权限。
- 后端入参优先专用 DTO / 强类型取值；关键字拆分后 `whereLikes`；软删 `whereIsOrNull("SYS_Deleted", 0)`（见 [代码风格规范.md](./代码风格规范.md)）。
- Guid 条件用 `whereGuid`（见 [数据库查询.md](./数据库查询.md)）。

---

## 6. 富选 Biz 页

- 选择器只嵌入 `Biz_*Select`，不在 put 内再包 `el-dialog`（基座 more panel 已是弹层）。
- 上下文通过 props（`param` / `conditions`）传入，命名跟随富选页。
- Select VC 可用卡片面；主按钮「选中」与工具栏确认同一路径；隐藏编辑/删除等修改类操作。

---

## 7. 新建检查清单

1. 确认实体主键与显示名字段。  
2. 后端增加 `sh/<名>`（或等价）轻量查询。  
3. 前端 `loadXxxSelector`。  
4. `uipart/xxxrow.vue` + `xxxput.vue`（selectorbase + onload + option + mbody）。  
5. 适配富选事件为统一 `@select`。  
6. `defineExpose({ openMorePanel })`。  
7. 表单用 `v-model:fk` / `v-model:name` 自测：下拉、更多、清空。

---

## 8. 反模式

| 反模式 | 应改为 |
|--------|--------|
| 表单手写 `el-dialog` + Biz 列表页 | 使用 `*put` |
| 下拉直接调列表 `qlist` | 使用轻量 `/…/sh/*` |
| put 把富选事件名直接暴露 | put 统一 `emit('select', row)` |
| 只绑 `name` 不绑 `fk` | 外键与显示名成对 |
| 在 `*row` 里发请求或改表单 | 行组件只展示 |
| 修改 `selectorbase` 塞业务字段 | 业务扩展写在 put / 富选 props |
| 把业务 put 放进 `web/src/ui/` | 放 `widgets/{widget}/uiext/` |
