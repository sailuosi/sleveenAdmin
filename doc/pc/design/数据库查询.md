## 2. Guid 主键 / 外键：必须 `whereGuid`

### 2.1 适用列

| 类别 | 命名习惯 | 示例 |
|------|----------|------|
| 主键 | `{表名}OID` | `Sa_EbNoteOID`、`Sa_EbCataOID`、`Sa_EbMatOID` |
| 外键 | `{表名}_FK` 或业务约定 FK | `En_Cata_FK`、`Tm_TopicOID`、`Tm_MatOID` |

列在实体中已为 `Guid?` / `Guid` 时，**相等条件禁止**普通 `.where(列, oid)`，**必须** `.whereGuid(列, oid)`。

### 2.2 原因

`whereGuid` 会校验入参是否为合法 Guid：非法或空 → 条件衰减为 `1=2`，避免脏字符串打进 Guid 列比较；在严格类型方言下还会携带 Guid 类型提示。

### 2.3 写法

```csharp
// ❌ 普通 where：无 Guid 校验，脏值可能进库比较
kit.where("mtb.Sa_EbNoteOID", oid);
kit.where("mtb.En_Cata_FK", cataFk);

// ✅
kit.whereGuid("mtb.Sa_EbNoteOID", oid);
kit.whereGuid("mtb.En_Cata_FK", cataFk);
```

集合条件用 **`whereInGuid`**（支持 `IEnumerable<Guid>` / `Guid?` / `string` 等重载）；空列表或非法集合按 mooSQL 约定衰减，勿手写拼 IN 字符串。

```csharp
// ✅
kit.whereInGuid("Sa_EbNoteOID", oids);

// ❌
kit.where("Sa_EbNoteOID in ('" + string.Join("','", oids) + "')");
```

### 2.4 仍可用普通 `where` 的情况

- 列本身是**字符串**承载的 Guid 文本（历史兼容字段）：注明原因后可用 `.where`，比较值用 `"D"` 格式。
- 非 OID 语义的编码（层次码、业务编码、证件号等）：保持字符串 `.where`。
- 表达式 / 子查询比较：`.where(列, op, subKit => …)` / `whereFormat`；子查询内对 Guid 列仍优先 `whereGuid`。

## 3. Bool：条件与赋值

### 3.1 WHERE

- 布尔列比较**直接传 `bool` / `bool?`**，禁止传 `"true"` / `"false"` / `"0"` / `"1"` 字符串（除非列本身是字符串类型）。
- 软删等「等于某值 **或** NULL」用 **`whereIsOrNull`**，禁止手写 `ISNULL(col,v)=v`。
- 本仓软删列多为整型 `0/1`：`whereIsOrNull("mtb.SYS_Deleted", 0)`（与 `BizServiceBase` 一致）。

```csharp
// ❌
kit.where("Em_Active", "true");
kit.where("ISNULL(SYS_Deleted,0)=0");

// ✅
kit.where("Em_Active", true);
kit.whereIsOrNull("mtb.SYS_Deleted", 0);
```

### 3.2 SET

从 `object` / `DataRow` 单元格等**类型不确定**的来源写入 bool 列时，用 **`setBool`**（转换失败可按 mooSQL `SetNullOpt` 忽略或写 NULL）。

已持有 `bool` / `bool?` 的强类型变量时，`.set("Col", flag)` 即可；触达改造或来源含混时优先 `setBool`。

```csharp
// ✅ 来源不确定
kit.setBool("Em_Active", row["Em_Active"]);
kit.setBool("SYS_Deleted", false);

// ✅ 已是 bool / 整型软删
kit.set("Em_Active", true);
kit.set("SYS_Deleted", 0);
```

## 4. 常规字符串：条件与赋值

### 4.1 WHERE

- 相等：`.where("Col", text)`，值为 `string`；入参可先 `Trim`，**禁止**在 SQL 里对列包 `LTRIM`/`RTRIM`/`UPPER`/`LOWER`。
- 模糊：`.whereLike` / `.whereLikeLeft` / `.whereLikes` 等，禁止手写 `'%' + x + '%'` 拼进条件串。
- **禁止**字符串拼接产生 WHERE 片段。

```csharp
// ❌
kit.where("En_Title='" + title + "'");
kit.where("UPPER(LTRIM(RTRIM(En_SourceUrl)))", url);

// ✅
kit.where("En_Title", title);
kit.where("En_SourceUrl", url.Trim());
kit.whereLike("mtb.En_Title", keyword);
kit.whereLikes(["mtb.En_Title", "mtb.En_Summary"], keyword);
```

### 4.2 SET

从 `object` / `DataRow` 等不确定来源写入字符串列时，用 **`setString`**。已是 `string` 可直接 `.set("Col", s)`。

```csharp
// ✅
kit.setString("En_Title", row["En_Title"]);
kit.set("En_Status", status);   // status 已是 string
```

## 5. SET 侧 Guid（与 whereGuid 配套）

写入 Guid 主键 / 外键列：

- 来源不确定 → **`setGuid`**
- 已是 `Guid` / `Guid?` → `.set("Col", oid)` 原样传，**禁止** `.set(..., oid.ToString())`（目标列为 Guid 时）

```csharp
// ❌
kit.set("En_Cata_FK", cataOid.ToString());

// ✅
kit.setGuid("En_Cata_FK", row["En_Cata_FK"]);
kit.set("En_Cata_FK", cataOid);
```

## 6. 速查表

| 列类型 | WHERE（相等） | WHERE（集合 / 可空） | SET（来源含混） | SET（已强类型） |
|--------|---------------|----------------------|-----------------|-----------------|
| Guid 主键 `*OID` | **`whereGuid`** | `whereInGuid` | `setGuid` | `set(col, guid)` |
| Guid 外键 `*_FK` | **`whereGuid`** | `whereInGuid` | `setGuid` | `set(col, guid)` |
| bool / 整型软删 | `where(col, bool\|0)` | 可空相等 → `whereIsOrNull` | `setBool` / `set` | `set(col, …)` |
| 常规 string | `where(col, string)` | 模糊 → `whereLike*` | `setString` | `set(col, string)` |
