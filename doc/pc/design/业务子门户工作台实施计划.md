# 业务子门户工作台实施计划

> **状态**：设计规范（子门户外壳 + `paotal` 装配的标准路径）  
> **目录**：`doc/pc/design/`  
> **定位**：在业务中心落地「域工作台」——把某业务域功能以可配置门户卡片集成到一屏；本仓门户引擎与设计器已具备，本文约定外壳落位与实施纪律。

---

## 1. 目标与边界

### 1.1 产品目标

落地**业务子门户工作台**：把域内功能（列表、看板、快捷入口、待办摘要等）以可配置门户卡片的方式集成到一屏，支持：

| 能力 | 说明 |
|------|------|
| 门户装配 | 按门户配置加载布局与 Portlet（沿用现有门户引擎） |
| 门户切换 | 同一外壳下可在多套门户方案间切换（角色/场景差异） |
| 个性化 | 支持用户侧布局/参数个性化（由 `paotal.vue` 承接） |
| 选择记忆 | 切换结果写入浏览器本地缓存，下次进入自动还原 |

### 1.2 非目标（本阶段）

- 不重写 `paotal` / `portlet` / 门户设计器核心引擎。
- 不把各业务页搬进 `portal` 目录；业务逻辑与列表/编辑页仍留在原业务文件夹。
- 不强制一期完成全部 Portlet；优先打通外壳 + 装配 + 切换缓存，再按卡片分批挂载。

### 1.3 成功标准

1. 菜单可进入 `Biz_*Portal*` 外壳，能按门户 Key/Oid 渲染工作台。  
2. 用户切换门户后刷新/重进可还原上次选择（本地缓存）。  
3. Portlet 内容组件仍落在业务域目录；门户目录只放外壳（直接挂 `paotal`）。  
4. 文档与目录结构可直接复制到后续子门户。

## 2. 前端架构

### 2.1 分层

```
┌─────────────────────────────────────────────────────────────┐
│  Biz_*Portal*.vue（固定外壳 · 路由/菜单入口）                 │
│  · 调起 / 切换门户                                           │
│  · 本地缓存：读写当前选中门户                                │
│  · 传入 name / oid / para，直接挂载 paotal.vue               │
│  · 不承载具体业务卡片实现                                     │
├─────────────────────────────────────────────────────────────┤
│  @/ui/portal/paotal.vue（门户装配与个性化 · 直接使用）         │
│  · 配置加载、格子布局、Portlet 渲染                           │
│  · 个性化保存走现有 savePortCells 等能力                      │
├─────────────────────────────────────────────────────────────┤
│  Portlet VC（vc*.vue）· 仍按职能分布在业务文件夹              │
│  · A_Key 与 vcholder dynamicImport 规则一致                  │
│  · 例：officeman / sailflow / sysext 业务子目录下的 vc*.vue  │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 职责划分

| 组件 | 职责 | 禁止 |
|------|------|------|
| **Biz_*Portal*** | 入口壳；门户列表展示与切换；本地缓存读写；把当前门户标识与共享 `para` 传给 `paotal.vue` | 不写具体业务查询；不直接拼 Portlet 布局；不自造装配层 |
| **paotal.vue** | 现有门户引擎：配置加载、布局渲染、个性化保存、参数透传 | 不在业务目录复制/改名一份；各子门户直接引用 `@/ui/portal/paotal.vue` |
| **业务 Portlet** | 卡片 UI + 业务请求；点击跳转/打开已有 Biz 页 | 不依赖外壳内部实现细节；只认 `vc/cell/para` 约定 |

### 2.3 与现有门户体系的关系

| 现有资产 | 本方案用法 |
|----------|------------|
| `@/ui/portal/paotal.vue` | **外壳直接引用**，负责格子布局与配置加载 |
| 门户公共 API | `getPortConfig` / `getPortConfigByOid` / `savePortCells`（由 `paotal` 内部调用） |
| `vcholder` + 动态导入 | Portlet 按 `A_Key` 动态加载 `@/widgets/**/vc*.vue` |
| `widgets/portaldesign` | 门户设计 / 配置 UI |
| `views/portal/*` | 门户配置、页面、控件管理入口 |

> **约定（R2）**：装配层**直接使用** `@/ui/portal/paotal.vue`，不新增 `portal.vue` 门面。后续各业务中心外壳同样直接挂 `paotal`。

## 3. 代码目录

### 3.1 门户外壳（按域新建）

根路径示例（以 officeman 为例，其它 widget 同构）：

```
web/src/widgets/officeman/views/{domain}/portal/
```

建议文件：

```
portal/
├── Biz_{Domain}Portal.vue       # 固定外壳（菜单/路由注册名与此一致；内部直接 import paotal）
├── Biz_{Domain}Portalapi.js     # 若需拉「可选门户列表」等接口（可薄包装）
├── usePortalSelectionCache.js   # 本地缓存读写（可抽公共，供后续中心复用）
└── README.md                    # 本目录约定（入口、缓存键、扩展模板）
```

> 不在本目录新增 `portal.vue`；装配组件统一为 `@/ui/portal/paotal.vue`。

### 3.2 业务子组件归属（不进外壳目录）

| 类型 | 放置位置 | 说明 |
|------|----------|------|
| 域内门户卡 | 对应业务文件夹下 `vc*.vue` | 在门户配置中挂 Key；须落在 `@/widgets` 下以便动态导入 |
| 深层业务页 | 既有 `Page/`、`VC/` | 卡片只做入口，打开 live 页 / 路由跳转 |

### 3.3 路由 / 菜单

- Biz 名：`Biz_{Domain}Portal`（与文件名一致）  
- 前端组件路径指向上述 `portal/Biz_*.vue`  
- 业务中心菜单挂接该 Biz（具体菜单 OID / 权限按现网配置）

## 4. 外壳详细设计

### 4.1 调起

1. 进入页后调用本页接口拉取可选门户列表（按约定 `P_Key` 前缀过滤，如 `whereLikeLeft`）。  
2. 读取本地缓存中的「当前门户」标识（Key 或 Oid），在列表中校验。  
3. 无缓存 / 无菜单强制参数则取列表首项。  
4. 将 `name` / `oid` 与共享 `para` 传给 `paotal.vue` 完成装配（**不修改** `paotal.vue`）。

### 4.2 切换

- UI：下拉 / 页签 / 侧栏列表（实现时选一种）。  
- 切换后立即更新当前标识 → 写本地缓存 → 重新挂载或更新 `paotal` 的 `name`/`oid`（建议 `:key` 强制重建）。

### 4.3 本地缓存约定

| 项 | 约定 |
|----|------|
| 存储介质 | `localStorage`（浏览器本地；非服务端偏好） |
| Key 命名 | `sleveen.portal.selection.{center}.{domain}` |
| Value | JSON，至少含 `portalKey` 和/或 `portalOid`、`updatedAt` |
| 作用域 | 建议附加 `userId` 后缀或写入 Value，避免同机多账号串用 |
| 失效 | Key/Oid 在可选列表中不存在时丢弃缓存并回落默认 |

示例：

```
sleveen.portal.selection.officeman.ebook
sleveen.portal.selection.sailflow.todo
sleveen.portal.selection.sysext.home
```

缓存读写抽到 `usePortalSelectionCache.js`（或提升到 `web/src/ui/portal/` 公共 hook），**禁止各外壳复制粘贴散落 key 字符串**。

### 4.4 共享参数 `para`

外壳可向装配层注入与工作台相关的上下文（按需）：

- 当前用户 / 机构（优先用现有 auth store，勿重复拉用户）  
- 业务中心标识、默认钻取范围等  

卡片内通过既有 portal VC 参数约定消费；外壳不解析卡片私有参数。

## 5. paotal.vue 用法（外壳直接挂载）

### 5.1 外壳引用方式

```vue
import paotal from "@/ui/portal/paotal.vue";
```

```vue
<paotal
  v-if="currentPortalKey"
  :key="currentPortalKey"
  :name="currentPortalKey"
  :para="sharePara"
  :disabled="true"
  class="biz-portal-paotal"
/>
```

按 Oid 加载时传现有 `oid` prop（与 `paotal` / `getPortConfigByOid` 对齐）。

### 5.2 常用 Props（沿用引擎，不另造）

| Props | 说明 |
|-------|------|
| `name` | 门户 Key，与 `getPortConfig` 对齐 |
| `oid` | 可选；按 Oid 加载时用 `getPortConfigByOid` |
| `para` | 共享参数对象 |
| `disabled` | 是否只读（不可拖拽保存布局）；工作台默认 `true` |
| `grid` | 是否固定 grid 渲染（`paotal` 默认行为） |

| Events | 说明 |
|--------|------|
| `changePara` | 参数变更；外壳可合并进共享 `para` |

### 5.3 个性化

- 查看态：`disabled=true`（工作台默认）。  
- 若产品要求终端用户改布局：外壳提供「个性化」入口，将 `disabled` 置 false；保存由 `paotal` 走 `savePortCells`。  
- 个性化策略以门户后台配置为准；外壳不自造第二套存储。

### 5.4 实现要点

- 高度：外壳给满屏 `flex`/`height:100%`，`paotal` 跟随滚动，避免双滚动条。  
- Key 切换时用 `:key="portalKeyOrOid"` 强制重建，避免旧格子残留。  
- **禁止**在域 `portal/` 下复制或再包一层与 `paotal` 同职责的组件。

## 6. 内容规划原则

### 6.1 卡片挂载

| 步骤 | 说明 |
|------|------|
| 1 | 确认卡片能力与跳转目标 Biz 页 |
| 2 | 文件名 `vcXxx.vue`，放在业务文件夹 |
| 3 | 在域内 keys 清单（若有）登记路径 |
| 4 | 数据库控件 / 单元格 Key 填同一字符串 |
| 5 | 请求走项目统一 request 与同目录 `*api.js` |

### 6.2 新增卡片原则

1. 业务卡片**不进**外壳 `portal/` 目录。  
2. 卡片只做入口与摘要，不复制完整列表/编辑页。  
3. 布局由门户设计器配置，不在代码里写死坐标。

## 7. 实施批次（模板）

| 批次 | 主题 | 产出 | 优先级 |
|------|------|------|--------|
| **P0** | 目录 + 外壳直接挂 `paotal` | 域 `portal/` 下 `Biz_*Portal.vue`、缓存 hook、README | P0 |
| **P1** | 门户切换 + 本地缓存 | 列表接口 + 下拉切换 + `localStorage` 还原 | P0 |
| **P2** | 菜单与默认门户配置 | 业务中心菜单挂接；门户 Key 前缀约定落地 | P0 |
| **P3** | 挂载首批卡片 | 复用/新建卡片完成一屏可用工作台 | P1 |
| **P4** | 个性化（可选） | 终端保存布局开关与权限 | P2 |
| **P5** | 标准沉淀 | README 升格为「子门户实施模板」；复制到下一中心 | P1 |

### 验收要点

- [ ] 外壳目录仅含外壳层文件（无自建 `portal.vue`）  
- [ ] 打开外壳能经 `paotal` 渲染指定 Key 的门户  
- [ ] 切换后刷新仍为上次选择；非法 Key 回落默认  
- [ ] 卡片源码不在外壳 `portal/` 下

## 8. 后续子门户标准路径（模板）

| 项 | 约定 |
|----|------|
| 外壳 Biz | `Biz_{Domain}Portal` |
| 目录 | `web/src/widgets/{widget}/views/{domain}/portal/` |
| 装配组件 | 直接 `@/ui/portal/paotal.vue` |
| Key 前缀 | 按中心约定，如 `officeman.ebook` |
| 缓存键 | `sleveen.portal.selection.{center}.{domain}` |
| 卡片目录 | 业务文件夹 `vc*.vue` |

**强制约定（所有子门户）：**

1. 固定外壳只负责：调起、切换、本地缓存。  
2. 装配与个性化直接使用 `paotal.vue`，不另建门面层。  
3. 业务卡片不进外壳目录。  
4. 不 fork 第二套门户引擎。

## 9. 风险与依赖

| 风险 | 应对 |
|------|------|
| 门户配置未建 / Key 错误导致空白 | 外壳空态提示 + 默认 Key 常量文档化 |
| 同机多账号缓存串用 | Value 或 Key 绑定 `userId` |
| 动态导入找不到组件 | Key 必须与 widgets 下 `vc*.vue` 路径一致 |
