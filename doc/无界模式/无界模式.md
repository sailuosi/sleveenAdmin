# 无界模式 · 左栏无界 · 顶栏无界 · 门户模式

> **状态**：现行实现说明  
> **目录**：`doc/无界模式/`  
> **定位**：一篇说清多套能力的边界、开关、落点与背景穿透纪律。

相关：业务子门户外壳规范见 [业务子门户工作台实施计划.md](../pc/design/业务子门户工作台实施计划.md)。

---

## 理念

这里的**无界模式**，意在打破传统 Admin 框架里「菜单栏 · 页签栏 · 内容栏」三层下巴叠出的臃肿感，让菜单与内容区浑然一体、干净整洁，达到一种「无界」的观感。

为此特意设计了**无界类型**的页面组件：压缩并简化页签栏与顶栏，允许内容组件的背景色铺满整个屏幕，侧栏/顶栏以悬浮卡片或浮岛形态融入同一画幅，而不是再嵌一套实色壳。

---

## 1. 概念对照

| 名称 | 本质 | 开关 | 作用范围 |
|------|------|------|----------|
| **左栏无界** | 主题**布局模式** | `theme.layout.mode === 'vertical-card'` | 全局壳：侧栏圆角卡片 + 右侧整页 |
| **顶栏无界** | 主题**布局模式** | `theme.layout.mode === 'horizontal-card'` | 全局壳：顶部毛玻璃浮岛菜单 + 沉浸铺满内容 |
| **无界 Vue 组件** | 菜单/路由**页面形态** | `meta.menuType === '4'` | 当前路由：侧栏/页签悬浮、内容铺满 |
| **门户模式** | **业务装配**方式 | 页面挂 `paotal`（常配合无界页） | 当前页：可配置卡片网格 |

左栏无界典型组合：

```
主题：vertical-card（左栏无界）
  + 路由：menuType=4（无界 Vue）
  + 页面：homePage → BorderlessDiv → paotal（门户）
```

顶栏无界典型组合：

```
主题：horizontal-card（顶栏无界；普通页避让顶栏）
  + 路由：menuType=4（无界 Vue，允许穿透）
  + 可选：BorderlessDiv / paotal
```

| 能力 | 关键入口 |
|------|----------|
| App 挂布局 class | `web/src/App.vue` |
| 布局编排 | `web/src/layouts/base-layout/index.vue` |
| 浮顶栏能力 | `web/packages/materials` → `AdminLayout` `floatHeader` |
| 内容区 / mainpan | `web/src/layouts/modules/global-content/index.vue` |
| 无界留白 | `web/src/components/common/borderless-div.vue`（顶栏无界不预留侧栏宽） |
| 门户引擎 | `web/src/ui/portal/paotal.vue` |
| 首页门户壳 | `web/src/views/home/homePage.vue` |
| 内置无界路由 | `web/src/router/routes/builtin.ts` |

## 2. 左栏无界布局（vertical-card）

| 项 | 值 |
|----|-----|
| 产品文案 | 左栏无界 |
| 主题 mode | `vertical-card` |
| 默认 | `web/src/theme/settings.ts` → `layout.mode: 'vertical-card'` |
| i18n | `theme.layoutMode.vertical-card` |

这是**全局布局偏好**，与单个菜单的「无界 Vue」不是同一开关。

### 2.1 行为

`base-layout` 在 `isVerticalCard` 为真时：

| 行为 | 说明 |
|------|------|
| 顶栏 | 隐藏 |
| 侧栏 | `siderInset / siderRadius = 16`，圆角卡片 + `sider-card-shell` 毛玻璃 |
| 氛围底 | `<main>` 加 `glass-atmosphere` + `card-main-flow` |
| 页签 | 由 `tab.cardAnchor`（top / bottom / right / hidden）决定嵌入或浮层 |

左栏无界**不强制** `floatSider`；普通业务页仍可保留 mainpan 灰/白底。

### 2.2 DOM

`App.vue` 根节点挂与 mode 同名的 class：

```html
<div class="h-full vertical-card">…</div>
```

```css
.vertical-card { /* 当前主题为左栏无界 */ }
```

其它 mode 同理：`.vertical`、`.horizontal`、`.vertical-mix` 等。

### 2.3 与无界页叠加

| 组合 | 效果 |
|------|------|
| 仅 `vertical-card` | 卡片侧栏 + 氛围底；业务页可有 mainpan 壳 |
| `vertical-card` + `menuType=4` | 再叠加悬浮侧栏、内容穿透、BorderlessDiv |
| 非 card + `menuType=4` | 仍悬浮侧栏与穿透；inset/圆角仍启用 |

写「只在左栏无界生效」的样式用 **`.vertical-card`**，不要误用 `.borderless-content`。`glass-atmosphere` 在左栏无界**或**无界页都会挂，不能单独区分二者。

## 2.5 顶栏无界布局（horizontal-card）

| 项 | 值 |
|----|-----|
| 产品文案 | 顶栏无界 |
| 主题 mode | `horizontal-card` |
| i18n | `theme.layoutMode.horizontal-card` |

与 `vertical-card` 成对：无侧栏，菜单在顶部浮岛。穿透纪律与左栏无界相同——**仅无界页（menuType=4）允许内容穿透**。

### 行为

`base-layout` 在 `isHorizontalCard` 为真时：

| 行为 | 说明 |
|------|------|
| 侧栏 | 隐藏（`siderVisible=false`） |
| 顶栏 | 显示；`floatHeader` + `headerInset/radius=16` 浮岛 |
| 顶栏视觉 | `GlobalHeader` → `.header-island-shell` 毛玻璃 |
| 菜单 | 复用 `HorizontalMenu`；子菜单 hover 下拉 mega-menu（与普通顶栏一致） |
| 氛围底 | `<main>` 加 `glass-atmosphere` + `card-main-flow` |
| 普通页内容 | 挂 `horizontal-card-content-pad-top`（`inset*2 + headerHeight`），强制避让浮岛 |
| 无界页内容 | `borderless-content` 穿透；顶距由 `BorderlessDiv` 自行留白 |
| 页签 | 浮岛不占文档流，`cardAnchor` 含 top 时一律走 `CardTabHost` 浮层 |

根 class：`.horizontal-card`（`App.vue`）。

### 与无界页叠加

| 组合 | 效果 |
|------|------|
| 仅 `horizontal-card` | 浮岛顶栏 + 氛围底；普通业务页顶部强制留白，可有 mainpan 壳 |
| `horizontal-card` + `menuType=4` | 保留浮岛；内容穿透铺满；`BorderlessDiv` 避开顶岛 |
| 非 card + `menuType=4` | 仍按无界页规则；若无顶栏浮岛则不套顶距 class |

## 3. 无界 Vue 组件（menuType=4）

| 项 | 值 |
|----|-----|
| 产品文案 | 无界 Vue 组件 |
| 菜单字段 | `MenuType = 4` |
| 路由 meta | `meta.menuType: '4'` |
| 判定 | `base-layout` → `isBorderlessPage` |

### 3.1 行为

| 行为 | 说明 |
|------|------|
| `floatSider` | 侧栏浮层，不占 `left-gap` |
| 顶栏 / Footer | 隐藏（页签走浮层 `CardTabHost`） |
| `<main>` | `borderless-content` + `card-main-flow` + `glass-atmosphere` |
| `GlobalContent` | `show-padding=false`，`borderless=true` |
| mainpan | `mainpan-lv2--borderless`，去掉灰/白实底 |

### 3.2 如何配置

- 菜单管理选 **「无界 Vue 组件」**（值 `4`）  
- 内置示例：`builtin.ts` 首页 `menuType: '4'`  
- 动态路由需把后端 `menuType` 写入 `route.meta.menuType`

### 3.3 BorderlessDiv

路径：`web/src/components/common/borderless-div.vue`  

用 padding 给悬浮侧栏/页签让位（`CHROME_INSET=16`、`CHROME_GAP=8`）。

```vue
<div class="home-page"><!-- 外层铺氛围背景 -->
  <BorderlessDiv>
    <paotal ... />
  </BorderlessDiv>
</div>
```

**纪律**：全画幅背景挂在**页面最外层**，不要挂在 `BorderlessDiv` 上。

### 3.4 新无界页检查清单

1. `MenuType = 4`  
2. 根容器 `height: 100%`（氛围底设在此）  
3. 内层 `BorderlessDiv`  
4. 不依赖 mainpan 灰/白壳；卡片感在业务内自建  
5. 挂门户则见下一节

## 4. 门户模式

门户模式 = 用 **`paotal` 装配可配置卡片网格**，而不是单页写死布局。

| 层 | 组件 | 职责 |
|----|------|------|
| 外壳页 | `homePage` / `Biz_*Portal` | Key/Oid、切换与缓存；挂载 `paotal` |
| 引擎 | `@/ui/portal/paotal.vue` | 配置、格子、Portlet、个性化 |
| 卡片 VC | `widgets/**/vc*.vue` | 业务 UI |

统一引用 `@/ui/portal/paotal.vue`，不在业务目录复制引擎。

### 4.1 推荐壳（与无界组合）

```vue
<div class="xxx-portal"><!-- 最外层：全画幅背景 -->
  <BorderlessDiv><!-- 仅留白，透明 -->
    <paotal :name="..." :oid="..." :disabled="true" />
  </BorderlessDiv>
</div>
```

| 纪律 | 说明 |
|------|------|
| 背景在外壳最外层 | 不在 BorderlessDiv / 不在 layout 全局改业务页 |
| `paotal` 页面底穿透 | `--portal-page-bg: transparent` |
| 欢迎类 Portlet | 勿再铺与外壳同色的大底 |

### 4.2 首页参照

`web/src/views/home/homePage.vue`：`getHomePortal` → `BorderlessDiv` → `paotal`；`.home-page` 铺欢迎同源渐变。

### 4.3 业务子门户

```
web/src/widgets/{domain}/views/.../portal/
├── Biz_{Domain}Portal.vue
└── …
```

菜单建议 `menuType=4`；切换缓存等见实施计划文档。

### 4.4 门户检查清单

- [ ] 外壳最外层 `height: 100%`，背景只这一层  
- [ ] `BorderlessDiv`（无界页）  
- [ ] `paotal` 页面底透明  
- [ ] 菜单 `menuType=4`（要悬浮侧栏 + mainpan 穿透时）  
- [ ] Portlet 不重复整页渐变  
- [ ] 未复制门户引擎

## 5. 背景穿透与 CSS 选择器

### 5.1 选择器速查

| 意图 | 选择器 |
|------|--------|
| 左栏无界主题 | `.vertical-card`（App 根） |
| 无界 Vue 页 | `main.borderless-content` |
| 无界 mainpan | `.mainpan-lv2--borderless` |
| 氛围底（card 或无界页） | `main.glass-atmosphere` |

### 5.2 分层

```
App.vertical-card
└── main.borderless-content.glass-atmosphere
    └── .mainpan-lv2--borderless     ← 必须透明
        └── .home-page               ← 全画幅氛围（外壳）
            └── BorderlessDiv        ← 仅 padding
                └── .paotal-top      ← 页面底 transparent
                    └── 卡片
```

| 层 | 背景 |
|----|------|
| 无界 `mainpan-lv2` | 否（去 `#f4f7f9`） |
| 无界页面根默认白壳 | 否（去 `#fff`）；可自设氛围 |
| 页面最外层 | **是**（一体感时） |
| BorderlessDiv / paotal 页底 | 否 |
| Portlet 卡片 | 可有 |

非无界业务页可继续用 mainpan 灰/白壳，勿全局拆掉。

### 5.3 穿透实现位置

| 文件 | 作用 |
|------|------|
| `App.vue` | `.vertical-card` 等 |
| `base-layout` | `.borderless-content`、`.glass-atmosphere` |
| `global-content` | `mainpan-lv2--borderless`、`bg-transparent` |
| `global.css` | 默认 mainpan 灰/白（非无界） |
| `homePage.vue` | `.home-page` 氛围 |
| `paotal.vue` | `--portal-page-bg: transparent` |

### 5.4 踩坑

1. 背景挂在 BorderlessDiv → inset 接不上侧栏。  
2. 只改 paotal、不设 `menuType=4` → mainpan 仍挡色。  
3. 用 `.glass-atmosphere` 当左栏无界开关 → 无界页也会挂。  
4. 欢迎 Portlet 与外壳同色大底 → 叠两层；hero 宜透明。

### 5.5 首页验收

1. App 根可见 `vertical-card`（默认主题）。  
2. `<main>` 含 `borderless-content`；有 `.mainpan-lv2--borderless`。  
3. 侧栏旁 inset 与卡片间隙透出同一渐变。  
4. `.paotal-top` 计算背景为透明。
